# TG视频下载

用你自己的 Telegram 账号，把已经能看到的视频保存到电脑。  
即使官方客户端隐藏了“下载”按钮（例如频道开启了 Restrict Saving Content / 限制保存内容），只要当前账号能打开并观看该视频，一般也可以通过官方用户 API 保存。

本工具只使用 [Telegram 官方用户 API](https://core.telegram.org/api)（通过 [Telethon](https://github.com/LonamiWebs/Telethon)），需要你用自己的手机号登录，不会访问你未登录、未加入的账号或对话。

- 系统：Windows 10 及以上
- 推荐：下载安装包 `TGVideoDownloader-Setup-*.exe`，可自定义安装位置（无需安装 Python）
- 也可使用便携版，或从源码运行（Python 3.10 及以上，需勾选 tcl/tk）

## 快速开始（推荐：安装包）

1. 从本仓库 [Releases](../../releases) 下载 `TGVideoDownloader-Setup-1.3.15.exe`，或使用本地打包结果 `dist/TGVideoDownloader-Setup-1.3.15.exe`。
2. 双击安装包，按向导选择安装目录（默认在 `C:\Program Files\TGVideoDownloader`，也可改到任意磁盘），可选创建桌面快捷方式。
3. 首次运行时，Windows 可能提示“已保护你的电脑”（未做代码签名），点 **更多信息** → **仍要运行**。
4. 按下面步骤申请 `api_id` / `api_hash`，再用同一手机号完成登录。
5. 国内网络请先打开能访问 Telegram 的 VPN，或在软件里填写本地代理。

安装版的登录信息保存在 `%LOCALAPPDATA%\TGVideoDownloader\data`。新安装时，默认下载目录是「下载」文件夹下的 `TG视频下载`（例如 `C:\Users\你的用户名\Downloads\TG视频下载`），可在软件里更改。若你以前改过保存位置，会继续用上次的目录。卸载程序不会删除这些个人数据。请不要把 `data` 或 `.session` 文件上传到 GitHub。

### 便携版

若不希望安装，可下载 `TGVideoDownloader-Portable-1.3.15.zip`，解压到任意文件夹后双击 `TGVideoDownloader.exe`。便携版会把登录会话和下载文件写在 exe 旁边的 `data`、`downloads` 里。

### 本地打包

- 只生成 exe：双击 `build_windows.bat`，结果在 `dist\TGVideoDownloader.exe`。
- 生成可安装的 Setup：双击 `build_installer.bat`（会先打包 exe，再编译安装向导）。需要本机已安装或允许自动安装 [Inno Setup](https://jrsoftware.org/isinfo.php) 6。
- 推送 `v*` 标签时，GitHub Actions 会自动生成安装包和便携版压缩包，并挂到 Release。

### 从源码运行

1. 安装 [官方 Python](https://www.python.org/downloads/)（3.10+），安装时勾选 **Add python.exe to PATH**。
2. 双击 **`启动.bat`**。首次运行会自动创建虚拟环境并安装依赖，可能需要一两分钟。
3. 按同样步骤申请 API 并登录。

也可以在本目录手动启动：

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

## 如何申请 api_id / api_hash

请使用**将要登录本工具的同一个手机号**：

1. 用浏览器打开 https://my.telegram.org ，用该手机号登录（会收到 Telegram 验证码）。
2. 进入 **API development tools**。
3. 如果还没有应用，随便填一个应用名称（例如 `TG Video Downloader`）、平台选 Desktop，创建即可。
4. 页面上会显示 **api_id**（一串数字）和 **api_hash**（一串字母数字）。
5. 把这两项填进本工具的首次配置窗口。它们只保存在本机的 `data/config.json` 中，请不要发给别人，也不要提交到网盘/代码仓库。

## 首次登录

1. 填写 api_id、api_hash 后点“保存并继续”。
2. 输入手机号。中国大陆可直接填 11 位手机号，程序会自动加上 `+86`；其他地区请带国际区号，例如 `+1...`。
3. 点“发送验证码”，在官方 Telegram 或短信中查看验证码并填入。
4. 若账号开启了两步验证（云密码 / 2FA），再填写密码后登录。
5. 登录成功后，本机会生成会话文件 `data/tg_session.session`，以后一般不必再输验证码。

验证码、两步验证密码和会话内容不会写入日志，也不会提交到任何服务器（只与 Telegram 官方通信）。

## 怎么下载

### 方式一：粘贴链接

在左侧「链接」页粘贴一条或多条消息链接（每行一条），例如：

- `https://t.me/用户名/123`
- `https://t.me/c/频道数字ID/123`（私密频道/群组）
- 带 `?comment=数字` 的评论链接（若解析失败，请改到讨论群里直接复制该条消息的链接）

支持普通视频、圆形视频（video note）以及以 MPEG/MP4 形式发送的动态 GIF。  
如果是相册（一组媒体），会下载该组里**所有视频**；纯图片相册会提示不含视频。  
链接下载会遵循与对话页相同的默认清晰度（未改时为最高画质）。软件不会在本地转码，只下载 Telegram 已提供的文件。

### 方式二：从对话下载

1. 打开左侧「对话」页，点「刷新」，可按名称搜索，也可用「全部 / 频道 / 群组 / 私聊 / 机器人」筛选。
2. 点选一个你已经加入、能看到内容的对话。列表使用 Telegram 头像（没有头像时才显示首字母）。
3. 右侧列出可下载的视频（新的在上），包括普通视频、圆形视频、动态 GIF、按文件发送的视频、网页里附带的视频文件和实况照片。下不了的（例如纯网页嵌入、未解锁的付费视频、直播）会留在列表里并写明原因，而不是悄悄跳过。较大封面右下角显示时长，下方为清晰度、体积和日期。
4. 勾选要保存的条目，或点「全选」，再点「下载选中」。可在「清晰度」中选择默认画质（默认最高；若一条视频只有一个文件，就下载该文件）。对话较长时点「加载更多」。

不必再填写消息 ID。开始下载后，进度显示在与链接页相同的任务列表中。

### 保存位置

新安装默认保存在用户「下载」目录下的 `TG视频下载`；便携版若该目录不存在，则退回到程序目录下的 `downloads`。可自行更改，程序会记住上次使用的目录。点「打开文件夹」可直接查看保存目录；一批任务结束后，任务列表标题栏也会出现同样的按钮。

文件名大致为：

```
日期时间_对话标题_消息ID_原文件名.mp4
```

已按 Windows 规则处理非法字符。

下载过程中，任务列表会显示文件名、体积、速度、进度条和百分比，一次会话里可以看到已完成、进行中和排队的项目。点「停止」会尽快中断当前文件；未下完的临时文件会被删除（Telegram 接口暂不支持可靠续传）。详细过程写在默认收起的「日志」里，需要时可展开并清空。

## 连不上 / 一直显示「正在连接」

国内网络常常访问不了 Telegram 服务器，软件就会一直停在「正在连接」。

1. 先打开能访问 Telegram 的 VPN，或 Clash / v2rayN 等代理（系统代理或 Tun 模式均可）。
2. 也可以在左侧边栏点 **代理**。若本机已开启 Clash / v2rayN 等常见端口，首次启动或点「检测本机」会尝试自动填入。建议类型选 `SOCKS5`，Clash Party 优先填 Socks 端口 `7891`（混合端口 `7890` 也可以），v2rayN 常见 `10808`。保存前可点「测试」，成功时会显示延迟。软件不会自动走系统代理，一般也不需要开虚拟网卡（TUN）。
3. 改完后请关闭软件再重新打开。安装版从开始菜单或桌面快捷方式启动即可；源码运行则再双击 `启动.bat`。

## 常见问题

**请求过于频繁 / Flood Wait**  
Telegram 有频率限制。程序会显示剩余等待时间并自动等待（也可点「停止」）。稍后再试即可，不要短时间内反复狂点下载。

**登录已失效 / 会话被撤销**  
在其他设备上终止了会话，或长时间未使用。在左侧边栏底部的账号菜单中点「退出登录」后，重新走一遍验证码流程。也可手动删除会话文件再打开程序：安装版在 `%LOCALAPPDATA%\TGVideoDownloader\data\tg_session.session`，便携版和源码运行在程序目录的 `data\tg_session.session`。

**两步验证密码不正确 / 验证码过期**  
密码请使用 Telegram 的云密码（不是锁屏密码）。验证码过期就重新点“发送验证码”。

**找不到对话 / 无权访问**  
只能下载**当前登录账号已经能看到**的内容。未加入的私密频道、已过期的邀请、已删除的消息都无法下载。若链接是 `t.me/c/数字ID/...`，请先在官方客户端里打开一次该对话，再回来下载。

**磁盘空间不足 / 文件过大**  
请更换保存目录或清理磁盘后重试。超大视频下载时间较长，请保持网络稳定。

**验证码没收到**  
确认手机号带了正确的国际区号；也可打开官方 Telegram 客户端查看“登录尝试”消息。

**启动.bat 提示找不到 Python 或没有 tkinter**  
请安装官方 Windows 版 Python 3.10+，勾选 PATH 以及 tcl/tk 组件后重试。

## 使用限制（请先了解）

- **不支持秘密聊天**（Secret Chat，端到端加密会话）。
- 不支持未加入、无权查看的私密频道 / 群组，以及已失效、已删除的链接。
- 不能绕过登录，也不会破解 Telegram；不会登录你未拥有的账号。
- 评论链接（`?comment=`）会尽量解析，失败时请改用讨论群中的消息链接。
- 超大文件受磁盘空间和网络稳定性限制，中断后可重新下载（不会覆盖已下完的同名文件，会自动加序号）。
- 请尊重内容作者与平台规则，仅保存你有权保存、用于个人备份的内容。

- 「对话」页改为左右分栏：左侧选对话，右侧自动列出可下载视频（封面及时长角标、体积、日期），可全选或勾选后点「下载选中」，并支持「加载更多」。不再使用「最近 N 条 / ID 范围 / 指定 ID」。

本版本未包含代码签名（仍可能出现 SmartScreen 提示）、自动更新，以及多连接加速下载（受 Telegram 接口限制）。窗口仍使用系统标题栏，客户区顶部另有一条应用顶栏。

### 1.3.0

- 全新浅色界面：窄侧栏切换「链接 / 对话」，任务列表作为主区域，日志默认收起，需要时再展开、清空。
- 新的应用图标（蓝底圆角方、白下载箭头）；窗口、exe、安装包和快捷方式都会使用该图标。
- 顶栏只保留账号入口：「登录」，或「已登录 · 名称」菜单（代理、退出登录）。版本号改到左侧「设置 → 关于」。
- 登录拆成独立步骤：首次「连接 Telegram」填写 API、再输入手机号和验证码，仅在需要时再出现「两步验证」。取消或关闭只会关掉弹窗。
- 代理窗口支持「直连 / SOCKS5 / HTTP」，可检测本机、测试连通并显示「已连通 · 延迟 xx ms」。
- 对话列表改为头像字 + 名称 + 频道/群组/私聊标签；下载方式一行写完（最近 N 条 / ID 范围 / 指定 ID）。
- 下载任务显示文件名、体积、速度、进度和百分比，一次会话中可同时看到已完成、进行中和排队的项目（仍是逐个下载）。

本版本未包含代码签名（仍可能出现 SmartScreen 提示）、自动更新，以及多连接加速下载（受 Telegram 接口限制）。窗口仍使用系统标题栏，客户区顶部另有一条应用顶栏。

### 1.2.0

- 登录窗口的「取消」或关闭按钮只会关掉该窗口，不再退出整个软件；主操作按钮更醒目，并在右上角单独提供「登录」。
- 可检测本机常见代理并测试能否连上 Telegram；首次启动若尚未填写代理，会尝试自动填入。
- 链接页支持一次粘贴多条链接；对话列表改为可滚动列表，不再受下拉框数量限制。
- 下载进度显示速度和剩余时间；停止会尽快中断当前文件。
- 默认保存位置改为「下载\TG视频下载」；中国大陆 11 位手机号自动补上 +86。
- 退出时彻底结束进程，减少挡住下次安装的情况。
- 首次运行会提示：请仅保存你有权保存、用于个人备份的内容，并遵守 Telegram 使用条款。

本版本未包含代码签名（仍可能出现 SmartScreen 提示）、自动更新，以及多连接加速下载（受 Telegram 接口限制）。
